# 🚗 Cadastro de Veículos

Projeto desenvolvido como atividade prática da disciplina de Linguagens de Programação, com o objetivo de criar um sistema de cadastro e consulta de veículos utilizando integração entre front-end, back-end e banco de dados.

O sistema permite cadastrar veículos disponíveis para venda e visualizar os registros armazenados em uma tabela dinâmica.

---

# 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- JSON
- XAMPP

---

# ⚙️ Funcionalidades

✔ Cadastro de veículos  
✔ Listagem de veículos cadastrados  
✔ Integração com banco de dados MySQL  
✔ Retorno de dados em formato JSON  
✔ Consumo de JSON com JavaScript  
✔ Campos obrigatórios no formulário  
✔ Interface web simples e funcional  

---

# 🧠 Conceitos aplicados

- Estruturação de páginas com HTML
- Estilização com CSS
- Manipulação de dados com JavaScript
- Desenvolvimento back-end com PHP
- Integração com MySQL
- Consultas SQL
- Comunicação utilizando JSON
- Operações CRUD (Create e Read)

---

# ▶️ Como executar o projeto

1. Instale o XAMPP
2. Inicie Apache e MySQL
3. Coloque a pasta do projeto dentro de:
C:\xampp\htdocs\

4. Importe o arquivo banco.sql no phpMyAdmin

5. Acesse no navegador:
http://localhost/cadastro-veiculos
